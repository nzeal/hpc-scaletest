===============
Getting Started
===============

Quick Start Guide for HPC-ScaleTest.

Installation
============

.. code-block:: bash

   git clone https://github.com/user/hpc-scaletest.git
   cd hpc-scaletest
   pip install -r requirements.txt

First Test
==========

Run a basic scaling test:

.. code-block:: bash

   python hpc_auto.py /path/to/code --scaling strong --nodes 16
